# Lựa chọn công nghệ React PWA và Supabase Realtime

Ứng dụng phục vụ gia đình sử dụng trên điện thoại di động và cần cập nhật tức thì khi các thành viên tương tác. Hệ thống lựa chọn giải pháp Web App di động (PWA) xây dựng trên React và Tailwind CSS, kết hợp cùng Supabase (PostgreSQL với Realtime subscriptions) để đồng bộ dữ liệu thời gian thực giữa các thiết bị mà không cần triển khai ứng dụng native lên App Store.
